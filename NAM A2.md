# Guitar NAM A2-Full or A2-Lite players
Created 260921

## Intro
- searching for (preferably) native NAM A2 modeler
- something smaller, for desk, not for floor
- for "bedroom"/hobby guitarist

Requirements:
- native NAM A2-Lite or A2-Full
- on unit editing, without Windows/phone app
- USB-C powered
- USB audio interface
- headphone out

[Introducing NAM A2 official](https://www.tone3000.com/blog/introducing-neural-amp-modeler-nam-architecture-2-a2)
- [Neural Amp Modeler](https://www.tone3000.com/guides/neural-amp-modeler) Architecture 2
- better than proprietary modeler architectures, according to some measurements
- democratizing of amps and cabinet models - free to download it from [tone3000](https://www.tone3000.com/)
- original architecture was designed for computer, A2 brings lower CPU usage
- A2 lite for low power pedals:
    - 50% CPU usage on 600 MHz ARM Cortex-M7
	- ["one A2 file can be run as A2-Full" ... "that same file can also be run as A2-Lite"](https://www.tone3000.com/blog/nam-a2-team)
- native players: Blackstar, Lava Music, Darkglass, HeadRush, Chaos Audio and Dimehead, dozens of major companies announcing support later this year.
- [no conversion](https://www.tone3000.com/guides/nam-a2-the-complete-guide#what-about-devices-that-use-nam-to-x-conversion)
- still no parameters
- browsing for hours tone3000 for good captures
- captures: [2dor for high gain, amalgam for low gain](https://www.reddit.com/r/NAM_NeuralAmpModeler/comments/1wp0i02/help_with_tone3000/), "AmpsPedalsPickups"
